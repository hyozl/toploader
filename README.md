# 오아라이브 탑꾸 공방

사진과 크림, 레진 파츠로 탑로더를 꾸미고 완성한 작품을 PNG로 저장하는 웹사이트예요.

- 사이트: https://oalive-topkku.pages.dev/

## 소개

- **목적**: 실제로 탑꾸(탑로더 꾸미기)를 하기 전에, 화면에서 미리 꾸며 보고 이미지로 저장하기
- **사용자**: 포토카드를 탑로더에 넣어 꾸미는 사람
- **상태**: 운영 중 (v1.0 · 2026-11-09 정식 배포, 바뀐 내용은 [docs/2026-11-09-release-v1.md](docs/2026-11-09-release-v1.md))

## 주요 기능

- **사진**: 내 사진 넣기, 위치·확대·회전 조절 (사진은 서버로 보내지 않고 브라우저 안에서만 처리)
- **케이스**: 테두리 색, 반짝이 가루, 위 테두리의 오아라이브 로고 각인
- **크림**: 테두리 크림을 꾸욱 눌러 짜기, 깍지 3종(별깍지·동글·물결), 색 직접 만들기·그라데이션, 진주·스프링클 뿌리기
- **파츠**: 레진 파츠 31종, 색 바꾸기, 좌우 반전, 내 사진으로 파츠 만들기(배경 자동 지우기)
- **글씨**: 입체 글씨, 글꼴 2종(동글·굵게), 흰색·검정
- 화면 확대·축소(버튼, 두 손가락, 마우스 휠, 두 번 톡, +·-·0 키, 확대 중 빈 곳 끌어 이동), 되돌리기·다시 실행, 다시 만들기, 효과음, 저장(PNG)
- **모바일**: 도구 시트 접기(같은 탭 다시 누르기·손잡이 쓸기), 작업대 위 되돌리기·다시 실행, 두 번 톡 확대, 공유 시트로 사진첩 저장, 진동 피드백, 홈 화면에 추가(앱처럼 실행), 가로 화면 배치, 카톡·인스타 등 앱 안 브라우저에서 "브라우저로 열기" 안내

## 폴더 구조

```
.
├── index.html          # 사이트 전체 (화면, 기능, 파츠 목록)
├── manifest.webmanifest # 홈 화면에 추가할 때 쓰는 앱 정보
├── og.jpg              # 카톡·SNS로 링크를 보낼 때 뜨는 미리보기 이미지 (1200×630)
├── icons/              # 홈 화면·탭 아이콘
├── parts/              # 파츠 이미지 (배경이 투명한 webp/png)
│   └── oalive-engrave.png   # 탑로더 위 테두리의 로고 각인
├── tools/
│   └── part_ref.py     # 새 파츠 이미지의 ref 값을 알려 주는 도구
├── docs/               # 기획서, 회의록 등 문서
├── src/                # (예비) 지금은 쓰지 않아요
└── README.md
```

빌드나 설치가 필요 없어요. `index.html`과 `parts/` 폴더만 있으면 돌아가요.

## 내 컴퓨터에서 실행하기

`index.html`을 더블클릭해서 열면 파츠 색 바꾸기와 PNG 저장이 막혀요(브라우저 보안 규칙). 아래처럼 간단한 서버로 열어 주세요.

```bash
git clone https://github.com/hyozl/toploader.git
cd toploader
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

## 배포

Cloudflare Pages가 이 저장소에 연결되어 있어서, `main`에 올리면 1~2분 뒤 자동으로 배포돼요.

- 대표 주소 (Cloudflare Pages): https://oalive-topkku.pages.dev/
- Cloudflare Pages 설정: Framework preset **None**, Build command 비움, Build output directory `/`

## 함께 수정하는 법

1. 저장소 **Settings → Collaborators**에서 수정할 사람을 초대해요.
2. 수정하는 사람은 `main`에 바로 올리지 않고, 새 가지(branch)를 만들어 고친 뒤 **Pull Request**를 열어요.
3. Cloudflare가 Pull Request마다 **미리보기 주소**를 자동으로 만들어 줘요. 실제 사이트는 그대로 두고 바뀐 모습을 먼저 확인할 수 있어요.
4. 문제없으면 **Merge** 하면 1~2분 뒤 실제 사이트에 반영돼요.

실수로 사이트가 깨지지 않게, **Settings → Branches**에서 `main`에 "Pull Request 승인 후에만 반영" 규칙을 걸어 두는 걸 추천해요.

## 파츠 추가하는 법

### 1) 이미지 준비

- 배경이 **투명한** png 또는 webp
- 파츠가 가운데 오고, 둘레에 여백이 조금 있게
- 색을 바꿀 파츠는 **흰색(무채색)** 으로 만들면 어떤 색이든 예쁘게 입혀져요
- 크기는 한 변 600px 정도면 충분해요 (너무 크면 사이트가 느려져요)

### 2) `parts/` 폴더에 넣기

예: `parts/heart.webp`

### 3) `index.html`의 `STICKERS` 목록에 한 줄 추가

```js
{ id:'heart', name:'하트', src:'parts/heart.webp', tint:true, ref:.85 },
```

- `id` — 영어로, 다른 파츠와 겹치지 않게
- `name` — 화면에 보이는 이름
- 목록 순서대로 파츠 탭에 나와요

### 4) 옵션

| 옵션 | 뜻 | 언제 쓰나요 |
|---|---|---|
| (옵션 없음) | 색이 바뀌지 않아요 | 무지개, 마이크, 로고처럼 색이 정해진 파츠 |
| `tint:true` | "파츠 색"으로 색을 바꿀 수 있어요 | 대부분의 파츠 |
| `ref:.85` | 원본 몸통의 평균 밝기 (0~1) | `tint:true`와 함께. 아래 도구로 확인 |
| `glass:true` | 투명한 보석처럼, 비치는 정도를 유지 | 보석, 클로버, 나비 |
| `metal:true` | 금속 느낌을 살려 색을 입혀요 (결·명암 유지, 빛나는 곳은 하얗게) | 십자가, 톱니바퀴 |
| `jelly:true` | 원본 색이어도 속이 반쯤 비치는 젤리 | 젤리 토끼·고양이·곰 |
| `only:'red'` | 빨간 부분만 색이 바뀌어요 | 체리 (꼭지·잎은 그대로) |
| `only:'white'` | 하얀 부분만 색이 바뀌어요 | 데이지 (가운데 노랑은 그대로) |
| `hi:.1` | 하얗게 남길 광택의 기준 (클수록 광택이 적게 남음) | 색을 입혔더니 하얀 점이 너무 많을 때 |
| `depth:1.3` | 그늘의 깊이 (기본 1.7) | 색을 입혔더니 너무 어둡거나 밋밋할 때 |
| `base:1.5` | 처음 붙일 때 크기 배율 | 체인·깃털처럼 길고 가는 파츠 |

### 5) `ref` 값 알아내기

```bash
pip install pillow numpy
python3 tools/part_ref.py parts/heart.webp
# → ref:.85 처럼 알려 줘요
```

## 문구·색 바꾸는 법

모두 `index.html` 안에 있어요. 아래 글자로 검색하면 찾기 쉬워요.

| 바꿀 것 | 검색어 |
|---|---|
| 사이트 이름 | `오아라이브 탑꾸 공방` (`<title>`, `og:title`) · 왼쪽 위 로고는 `<h1>` 안의 `class="logo"` 이미지 |
| 저장 완료 문구 | `오늘의 탑꾸 저장 완료` (미리보기 창과 알림 두 군데) |
| 빈 탑로더 안내 | `빈 탑로더예요` |
| 케이스 색 목록 | `CASE_COLORS` |
| 파츠 색 목록 | `PART_COLORS` |
| 글씨 색 목록 | `TEXT_COLORS` |
| 글꼴 목록 | `FONTS` (구글 폰트 주소도 맨 위 `<link>`에 함께 추가) |
| 로고 각인 위치·크기 | `drawBrand` |
| 글씨 입체 두께 | `글씨 두께` |
| 크림 광택 | `CREAM_GLOSS` |
