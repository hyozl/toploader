# 탑꾸 공방

사진과 크림, 레진 파츠로 탑로더를 꾸미고 완성한 작품을 PNG로 저장하는 웹사이트예요.

## 소개

- **목적**: 실제로 탑꾸(탑로더 꾸미기)를 하기 전에, 화면에서 미리 꾸며 보고 이미지로 저장하기
- **사용자**: 포토카드를 탑로더에 넣어 꾸미는 사람
- **상태**: 개발 중

## 주요 기능

- **사진**: 내 사진 넣기, 위치·확대·회전 조절 (사진은 서버로 보내지 않고 브라우저 안에서만 처리)
- **케이스**: 테두리 색, 반짝이 가루
- **크림**: 테두리 크림을 꾸욱 눌러 짜기, 직접 짜기, 깍지 3종, 색 직접 만들기·그라데이션, 진주·스프링클 뿌리기
- **파츠**: 레진 파츠 21종(리본·보석·체리·날개·구름·무지개·데이지·진주 하트·장미·체인·네잎클로버·깃털·나비·별·음표·진주 리본·단추), 색 바꾸기, 좌우 반전, 내 사진으로 파츠 만들기(배경 자동 지우기)
- **글씨**: 입체 글씨, 글꼴 6종, 색 바꾸기
- 되돌리기·다시 실행, 다시 만들기, 자동 저장과 이어하기, 효과음, PNG 저장

## 시작하기

빌드나 설치 없이 `index.html` 파일 하나로 동작해요.

```bash
git clone https://github.com/hyozl/toploader.git
cd toploader
# index.html 을 브라우저로 열면 바로 실행돼요
```

## 배포

GitHub Pages로 배포해요. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 설정하면 아래 주소로 열려요.

- https://hyozl.github.io/toploader/

수정할 때는 `index.html`을 바꿔서 `main`에 올리면 1~2분 뒤 사이트에 반영돼요.

## 파츠 추가하는 법

`index.html` 안의 `STICKERS` 목록에 한 줄씩 추가해요.

```js
{ id:'bow', name:'리본', src:'이미지 주소', tint:true, ref:.89 },
```

- `tint:true` — 색을 바꿀 수 있는 파츠
- `glass:true` — 투명한 보석류 (비치는 정도를 유지)
- `only:'red'` / `only:'white'` — 빨간 부분 / 하얀 부분만 색이 바뀌는 파츠
- `ref` — 원본 몸통의 평균 밝기 (색을 입힐 때 기준)
