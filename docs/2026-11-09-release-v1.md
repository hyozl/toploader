# 오아라이브 탑꾸 공방 v1.0 정식 배포 (2026-11-09)

- 사이트: https://oalive-topkku.pages.dev/
- 저장소: https://github.com/hyozl/toploader (`main`에 올리면 Cloudflare Pages가 1~2분 뒤 자동 배포)

## 들어간 기능

| 영역 | 내용 |
|---|---|
| 사진 | 내 사진 넣기, 위치·확대·회전 (사진은 서버로 보내지 않고 브라우저 안에서만 처리, 사진 탭에서만 움직임) |
| 케이스 | 테두리 색 6종 + 직접 고르기, 반짝이 가루, 위 테두리 오아라이브 로고 각인 |
| 크림 | 테두리(위·아래·왼쪽·오른쪽) 꾸욱 눌러 짜기, 깍지 3종(별깍지·동글·물결), 색 직접 만들기·그라데이션, 진주·스프링클 |
| 파츠 | 31종 (레진·젤리·보석·금속), 색 바꾸기, 좌우 반전, 복제, 맨 앞으로, 처음 크기의 10%~400%, 내 사진으로 파츠 만들기(배경 자동 지우기) |
| 글씨 | 입체 글씨, 글꼴 2종(동글·굵게), 흰색·검정 + 직접 고르기, 흰 테두리 |
| 화면 | 확대·축소(버튼·두 손가락·휠·두 번 톡·키보드), 확대 중 빈 곳 끌어 이동, 되돌리기·다시 실행, 다시 만들기, 효과음 |
| 저장 | PNG 저장 (편집 테두리·버튼 없이), 휴대폰은 공유 시트로 사진첩 저장, 앱 안 브라우저에서는 길게 눌러 저장 + "브라우저로 열기" 안내 |
| 모바일 | 한 화면 배치, 도구 시트 접기, 가로 화면 배치, 홈 화면에 추가(앱처럼 실행) |
| 글꼴 | 사이트 글꼴 프리텐다드 (못 불러오면 Noto Sans KR 등 고딕) |

## 배포 전 마지막 정리

- 크림 "직접 짜기"를 없애면서 남아 있던 코드 정리 (기능 변화 없음)
- 아이폰 13·아이폰 SE·PC·휴대폰 가로 화면에서 사진 → 케이스 → 크림 → 파츠 → 글씨 → 되돌리기 → 확대 → 저장 → 다시 만들기 흐름 점검, 오류 없음
